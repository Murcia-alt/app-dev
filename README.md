# John Wick

> *“People keep asking if I'm back, and I haven't really had an answer. But now, yeah, I'm thinkin' I'm back.”*  
> — **John Wick**

## Overview

**John Wick** is a neo-noir action thriller film series starring [Keanu Reeves](https://en.wikipedia.org/wiki/Keanu_Reeves) as the title character. Known for its stylized action, sleek cinematography, and an intriguing underworld of assassins, it's become a modern action classic.

---

## Films in the Series

1. **John Wick** (2014)
2. **John Wick: Chapter 2** (2017)
3. **John Wick: Chapter 3 – Parabellum** (2019)
4. **John Wick: Chapter 4** (2023)

---

## Main Characters

- **John Wick** – Legendary hitman
- **Winston** – Manager of the Continental Hotel
- **Charon** – Concierge at the Continental
- **The Bowery King** – Underground crime lord

---

## Key Features

- **Stylized Gun-fu Combat**
- **High-contrast Visuals**
- **Code-bound Assassin Society**
